# E-Commerce Management System

A Python-based desktop application built using Tkinter to simplify product and inventory management for small businesses.

### Features
- Add, view, and remove products.
- Search products by name or category.
- Filter products by stock status.
- Sell and restock products.
- Automatic stock status updates.
- Calculate total inventory value.
- Input validation to prevent invalid stock updates.

### Technologies Used
- Python 3
- Tkinter
- ttk (Themed Tkinter Widgets)

### How to Run
1. Install Python 3.
2. Clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python ecommerce_manager.py
```

### Note
This is a learning project. Product data is stored in memory and resets when the application is closed.
